# IMHS

自分と友人のための、日本語の小さなゲームランチャーです（静的サイト・ビルド不要・ログイン不要）。
Windows のブラウザ、iPhone の Safari／ホーム画面アプリ（PWA）で動き、初回の準備後はオフラインで遊べます。
広告・課金・アカウント・解析・プレイデータの外部送信はありません。

**公開URL: https://imahase00.github.io/imhs/** （ログイン不要。初回の準備後はオフラインで遊べます）

収録ゲーム:

- **マージの旅** ― 同じ品物を重ねて育て、3つの島の依頼をかなえて灯台に光を灯す合成パズル。
- **ひだまり菜園** ― 丘の上の菜園で野菜や花を育てて加工し、村の人の依頼にこたえて収穫祭をひらく、のんびり育成ゲーム。
- **森のとりで** ― 夜の森から押し寄せる魔物から村を守る見下ろし型アクション。コインを集めて台座で砦・仲間・武器を強化し、15の夜を守りきる。
- **漂流発明記 ― 霧の島 ―** ― 霧の島に墜落した発明家が、手作業から蒸気・ベルト・工場へと島を工業化し、飛行船を組み上げて脱出する見下ろし型の工業化ゲーム（シリーズ1作目。ゲームID `drift-1`）。

## Windows で起動する

1. `start-local.cmd` をダブルクリック
2. ブラウザで `http://127.0.0.1:8765/` が開きます（このウィンドウを閉じるとサーバー停止）

- Python 3（`py` または `python`）を優先し、無ければ Node.js を使います。どちらも無い場合は導入方法を表示します。
- ポート 8765 が別のアプリで使用中なら説明を表示して終了します（他のプロセスは終了させません）。
- `file://` で直接開くと保存・オフライン機能が動きません。必ず上記の方法で開いてください。
- ローカル（127.0.0.1:8765）と公開版（github.io）はブラウザ上で別サイト扱いのため、セーブも別々です。

## 公開版の更新（GitHub Pages）

公開元は `main` ブランチの `/docs` です。

```powershell
python tools/prepare_assets.py   # IMG/ の素材を差し替えたときだけ（ゲームIDを付けるとそのゲームの画像だけ作り直す）
node tools/build.mjs             # 必須: 同梱資産リストと Service Worker の版を更新
npm test                         # ルール・資産リストの検査
npm run test:e2e                 # （任意）Chrome/Edge で通し操作。初回のみ npm install
git add -A
git commit -m "更新内容"
git push
```

数分後に公開URLへ反映されます。遊んでいる人には次回起動時、またはランチャーの「更新する」で切り替わります（プレイ中に強制リロードはしません。セーブは更新の影響を受けません）。

## ゲームを追加する

1. `docs/games/<ゲームID>/` を作り、`index.html` と画像・音などを置く
   - 共通処理は `docs/shared/`（保存 `storage.js`・設定 `settings.js`・オフライン `sw-client.js`）を import して使えます
   - 盤面・通貨などゲーム固有の処理は各ゲームのフォルダ内に置き、`shared/` には入れないでください
2. バックアップ検証用モジュールを用意する（例: `games/hidamari-garden/save-schema.js`）
   - `SCHEMA` と `parseBackup(obj)` を export する。`parseBackup` は `{ ok, data, info }` を返し、`info.rows`（復元確認に表示する `[見出し, 値]` の配列）・`info.label`（セーブ一覧の見出し）・`info.coins` を含める
3. `docs/games.json` に登録する

   ```json
   { "id": "new-game", "title": "表示名", "subtitle": "ひとこと", "cover": "games/new-game/img/cover.webp",
     "entry": "games/new-game/index.html", "saveModule": "games/new-game/save-schema.js", "description": ["説明"] }
   ```
4. `node tools/build.mjs` → `npm test`（資産リストへの登録漏れ・外部URL・絶対パスを検査）

パスはすべて相対パスにしてください（`/imhs/` のようなリポジトリ配下でも動くようにするため）。

## 素材対応表

`ASSETS.md` に、`IMG/` の原本ファイル → 用途・ゲームID・配信パスの対応をまとめています。
`IMG/`（原本・画面見本）はリポジトリに含めません。原本はゲームごとのフォルダ（`IMG/マージの旅/`・`IMG/ランチャー/` など）に分けて置きます。配信用の縮小コピーは `docs/` 配下にあります。

## バックアップと復元

- ランチャー右上の ⚙ →「バックアップと復元」
- **バックアップを保存**: JSON ファイル（ゲームID・スキーマ版・日時入り）を保存。iPhone では共有シートが開くので「"ファイル"に保存」を選びます
- **ファイルから復元**: ゲームごとに形式・値を検証し、進み具合（マージの旅は島、ひだまり菜園は日付）・所持金・依頼数・日時を表示して上書きを確認します。壊れたファイルや新しすぎる版は拒否し、今のデータは変更しません
- Windows ⇔ iPhone の移行はこのファイルで手動で行います（自動同期はありません）
- ゲームを別タブで開いている間は復元できません（上書き防止）

1. 島をまたぐ任意依頼（例: しおかぜ島の人がこもれび島のケーキを頼む）を各島に2〜3件追加し、報酬で図鑑・収納拡張を後押しする

### iPhone 16 実機での確認手順

1. Safari で公開URLを開く →「共有」→「ホーム画面に追加」（名前が IMHS になっていること）
2. ホーム画面の IMHS を開き、「オフライン準備完了」が出るまで待つ
3. 機内モードにして IMHS を完全に終了（上スワイプで閉じる）→ 再起動
4. 「遊ぶ」→ 果樹を2回タップ → りんごを重ねて合成 → 納品
5. もう一度アプリを終了・再起動し、コインと盤面が残っていることを確認
6. BGM・効果音が鳴ること（消音スイッチがオンだと鳴りません）、盤面をドラッグしても画面がずれないこと
