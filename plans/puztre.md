## パズル（よくある連鎖パズルの仕組みそのまま）
- 盤面は 横6×縦5 の30マス。球は6種類
- 球を1つつかんで指でなぞると、通った球と入れ替わりながら動く。動かせるのは4秒（枠で延長）。指を離すか時間切れで確定
- 同じ色が縦か横に3つ以上並ぶと消える。消えた所へ上から新しい球が落ち、また並べば消える（落ちコン）
- 1回の操作で消えた組の数＝コンボ数。威力 = 色ごとの消した数 ×（1 + 0.25 ×（コンボ数 − 1））
- 5つ以上つなげて消すと、その組だけ威力1.5倍

| 球 | 主な役割 |
|---|---|
| 炎 | つた・木・氷をこわす |
| 水 | 溶岩・炎を冷やす |
| 草 | 根で岩を割る・つるで橋を架ける |
| 光 | 暗闇・呪い・影の仕掛けを払う |
| 影 | 光の仕掛け（鏡・天空の装置）を曇らせる |
| ハート | 探検隊の体力を回復（仕掛けには効かない） |

## 仕掛け（敵の代わり）
- 1フロアに1〜3個。それぞれ「耐久」「弱点の色（効く色）」「カウントダウン」を持つ
- 弱点の色は 2倍、ふつうの色は 1倍、効かない色は 0.25倍
- カウントダウンは操作のたびに1ずつ減り、0になると罠が作動して探検隊の体力が減る（天井が下がる・矢が飛ぶ・水があふれる など）
- 盤面への悪さ: 石の球（消せない・3手で砂に戻る）、暗闇（球の色が見えない）、凍結（動かせない球）など。後半のダンジョンほど増える
- 最奥はボス「大扉」。耐久が多く、2〜3段階で弱点が変わる

## 探検隊の道具（スキル）
- 道具を4つまで持ち込める。それぞれが「色ごとの力」と「スキル」を持つ
- スキルは何手か操作すると使えるようになる（待ち時間ではなく手数）
- 道具はダンジョンを突破すると手に入る（全16種、うち数種は隠しお宝と同じ条件）

| 道具 | スキルの例 |
|---|---|
| たいまつ | 草の球を炎に変える |
| 水筒 | 体力を回復し、炎の球を水に変える |
| つるはし | 石の球・凍った球をすべて壊す |
| ランタン | 暗闇を払い、影の球を光に変える |
| 鏡 | 光の球を増やす |
| 砂時計 | 次の操作の時間を2倍 |
| ロープ | 罠のカウントダウンを2戻す |
| 方位磁針 | 盤面を全部入れ替える |
| （ほか8種） | 作りながら調整 |

## 進み方・失敗・お金
- ダンジョンはフロアを順に進む。途中でやめても、そのダンジョンの到達フロアから再開できる
- 体力0で「撤退」。そのダンジョンで拾ったコインの半分と、見つけたお宝は残る。フロアは入口から
- クリアでコイン（ダンジョンが進むほど多い）。クリア済みダンジョンは何度でも挑めて、隠しお宝やコイン稼ぎに使える
- スタミナ・待ち時間・ガチャ・課金・ランキングはなし
