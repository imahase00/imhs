# イナビカリ 企画書（入口）

- ゲームID: `inabikari`
- ジャンル: 超次元サッカーRPG（町を歩いて物語を進め、試合はタッチ操作＋コマンドバトル）
- 舞台: 福岡県。弱小の甘栗中サッカー部が全国大会「カミナリ杯」優勝を目指す
- 位置づけ: 超次元サッカーものへのオマージュ。仕組みやノリは取り入れるが、人物・技・物語はオリジナル
- 見た目: 携帯ゲーム機時代の2Dドット風。AIっぽさが出ない、粗めのドットと少ない色数で統一する
- 遊ぶ時間の目安: 物語クリアまで 3〜5 時間（推定。完成後に自動プレイで計り直す）

## 決まったこと

- 主人公たちの名前: 米野 剛 / 若杉 雅也 / 南蔵院 遥斗
- 第一章の練習試合はボロ負け（案A）。出場資格は自分たちで申し込む
- 試合は 11対11、前後半あわせて実時間 5〜6 分
- 仲間は甘栗中の12人で固定（追加加入なし）
- 能力値: キック・ボディ・スピード・ガード・TP。レベルは 50 まで、50 は「MAX」と表示
- 負けたら、その試合の相手キャプテンに話しかける直前に戻る
- 言葉: 甘栗中と福岡の学校は博多弁。全国大会は香川・大阪・神奈川の言葉。全能学園は東京（標準語）
- 画面: 2画面の携帯ゲーム機風で、上3：下7。下は遊ぶ画面（ピッチ・町のマップ・タッチ操作）、上は見るだけの画面（スコア・縮図・会話・カットイン）
- 必殺技: 全27個が確定（[characters.md](characters.md)）。読みと演出案も確認済み
- 見た目: 小さいドットは手打ちし、顔と背景は生成画像をドット絵に変換する。全体で1つの色の表を使う
- 甘栗中で必殺技を使えるのは、米野・若杉・菊池・岩山・小林・来栖・工藤・和中
- 若杉は練習試合の直後に入部。全員でカミナリ杯へのエントリーを決意して第一章が終わる
- 必殺技の演出は下の7割で見せる。上の3割は技名と顔のカットインだけ。見せ場の技は2画面にまたがる
- 試合前にスタメン11人を選ぶ。交代はハーフタイムだけ。フォーメーションは3種類（標準・攻撃的・守備的）
- 強くなる手段は試合の経験値だけ（装備・お金はなし）。経験値は全員に入り、ベンチは少なめ。負けても経験値は残す
- 練習試合は 0−10 のあと剛が『大地の手』に目覚め、遥斗が切り上げる。若杉は土手から見ていて翌日入部。エントリーを言い出すのは菊池
- 若杉がサッカーを離れた理由は「一人で背負うサッカー」に疲れたから。江戸川青洲戦で古巣と決着をつける
- エンディングは表彰式→河川敷で剛と若杉→ごく短いスタッフロール（数秒・飛ばせる）
- 物語と町イベントは [story.md](story.md) の内容で確定
- IMHS はスーツを着た20代の青年
- モブの名前は地域ごとによくある名字から作り、後で直せるようにする
- 必殺技に属性の相性はない。勝ち負けは能力値と技の威力で決まる
- 文字は DotGothic16（無料で同梱できる。使い方の条件を書いたファイルも入れる）。ゲームで使う文字だけを切り出して軽くする
- 公開は章ごと。第一章が遊べるところで一度公開し、「第二章以降は準備中」と出す。章ができるたびに追加する
- モブの名前、各地の言葉のセリフ、BGM と効果音は Claude に任せる（言葉の違和感は遊びながら確認してもらう）
- 背景5枚はイベントの会話シーン用。下の7割に表示し、その上に小さなドットのキャラを立たせて動かす。町を歩くマップは手打ちのタイルで別に作る
