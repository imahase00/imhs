# 3本目「森のとりで」企画書（案）

## ひとことで
夜の森から押し寄せるいたずらな魔物たちから、小さな村を守る見下ろし型の拠点防衛アクション。
敵を倒してどんぐりコインを集め、強化エリアに立って砦・仲間・武器を育てていく。
広告で見るあの遊びを、そのまま遊べるゲームにする。

## 操作（iPhone 縦持ち・片手）
- 画面のどこかを押したまま指を動かすと、その方向へ主人公が歩く（指を置いた場所が仮想スティックの中心）。
- 攻撃は自動。射程内のいちばん近い敵をねらう（動いている間も撃てる。近接武器の間は止まると攻撃）。
- 強化エリアの上に立ち止まると、手持ちのコインが少しずつ吸い込まれ、たまると完成する。
- PC は WASD・矢印キーとマウスのドラッグでも動ける。

## 1回の流れ
1. **休憩時間（ウェーブの合間）**
   - 自由に歩き回れる。砦や仲間をながめたり、強化したりできる。
   - 森の端から弱い敵が少しずつ出てくる（同時に最大数体まで）。倒すとコインを落とすが、ウェーブ中より少なめ。
   - 画面の「次のウェーブへ」を押すまで、ウェーブは始まらない。ここでゲームを中断・保存できる。
2. **ウェーブ（夜）**
   - 画面が夜の色になり、決まった数の敵が四方の道から押し寄せる。
   - 敵は砦の中心（たき火の小屋）をめざし、途中の柵や仲間、主人公も攻撃する。
   - すべて倒すと朝になり、休憩時間に戻る。ウェーブ報酬のコインも手に入る。
3. 5ウェーブごとにボス。15ウェーブ目のボス「影の大イノシシ」を倒すとマップクリア。クリア後も休憩時間の稼ぎと強化、ウェーブの遊び直しができる。

## 体力と負けたとき（やさしい負け方）
- 主人公には体力がある。囲まれたり、ボスの大技を受けたりすると減る。休憩時間とたき火のそばで少しずつ回復する。
- 主人公が倒れたら、数秒後に砦の中心で復活する。ウェーブ中は仲間と設備が戦い続ける。
- 砦の中心が壊されたら、そのウェーブは失敗。そのウェーブの直前（休憩時間）に戻る。**強化と所持コインは失わない。**
- ボスの大技は、地面に赤い円や扇形で予告してから出す。避けられる。

## 育つもの（強化エリア）
| 系統 | 段階（見た目も変わる） | 効果 |
|---|---|---|
| 砦の中心 | 木の骨組み → 丸太小屋 → 石造りの家 → とりでの塔 | 中心の体力。次の段階で新しい強化エリアが開く |
| 柵・城壁（4方向それぞれ） | 骨組みの柵 → 丸太の柵 → 石垣 → 鉄で補強した城壁 | 敵の足止め。壊れても休憩時間に自動で直る |
| 主人公の武器 | 木の棒 → 弓 → クロスボウ → 蒸気仕掛けの銃 | 射程・攻撃力・連射。最後は「文明的な武器」 |
| 仲間 | うさぎの弓兵 / くまの盾兵 / りすの投石兵 / ふくろうの癒し手 | 人数と強さ。決めた持ち場の近くで自動で戦う |
| 見張り台 | 木の見張り台 → 石の見張り台 → 大砲台 | 置いた場所から遠くの敵を撃つ |
| 主人公 | 体力・移動の速さ・コインを引き寄せる範囲 | 小さな強化を何段階も |

- 強化エリアは一度に全部は見えない。砦の中心を育てると、新しいエリアが現れる。
- 主人公の武器の段階に合わせて、主人公の絵が持ち替わる（武器ごとに絵を用意する）。

## 敵（1マップ目）
| 敵 | 特徴 |
|---|---|
| いたずらキノコ | 弱い・遅い・数が多い。最初の相手 |
| 黒いオオカミ | 速い。柵のすき間をねらう |
| 影のカラス | 空を飛び、柵を越えてくる |
| どんぐり投げのサル | 離れた場所から投げてくる |
| 苔むした岩ゴーレム | 遅いが硬い。柵をよく壊す |
| トゲ毛虫 | 倒すと小さく分かれる |
| 夜の霧の精 | 仲間の攻撃を一時的にそらす（後半） |
| ボス: 影の大イノシシ | 突進（予告の帯）・地ならし（予告の円）。仲間の援護がないと勝てない強さ |

5・10ウェーブ目は中ボス（大きなオオカミ・大きな岩ゴーレム）。絵は通常の敵を大きく、色を変えて使う。

## 保存
- 休憩時間に入ったとき、強化したとき、休憩時間の稼ぎの途中（数秒ごと）に自動保存する。
- ウェーブの途中でアプリを閉じた場合は、そのウェーブの直前から再開する（ウェーブ中の敵の位置は保存しない）。
- これまでの2本と同じく、セーブは端末内のみ。バックアップと復元はランチャーから行う。

## 動きの表現（画像1枚ずつ＋プログラムで動かす）
- 歩く: 小さく上下にはずむ・少し傾く・向きに合わせて左右反転・足元の影。
- 攻撃: 「攻撃ポーズ」の絵に一瞬切り替え、前に縮んで伸びる。矢・石・弾が飛ぶ。
- やられる: 白く光って少し押し返される。倒れると縮んで消え、コインが散らばる。
- 建てる: 強化エリアが完成すると、建物がポンと大きくなって収まり、土ぼこりが舞う。
- 夜: 画面全体を青く暗くし、たき火・ランプ・見張り台の周りだけ明るくする。

## 技術方針
- これまでと同じ静的サイト。外部ライブラリなし、ブラウザ標準の Canvas で毎秒60回描く。
- iPhone で重くならないよう、同時に出る敵の数に上限を設け、使い終わったものを使い回す。画像は小さめに縮小して配信する。
- 強さの数値（体力・攻撃・費用・ウェーブ構成）はデータファイルにまとめ、調整しやすくする。
- 勝てるかどうかの目安は、自動で動く簡易ボットで確認する。ただしアクションなので、最終的な調整は試遊の感想で行う。
- 2マップ目以降（雪山、海辺、からくりの街など）は、地図・敵・見た目のデータを差し替えて増やせる作りにしておく。

## 遊ぶ時間（目標と見込み）
- 1マップ（15ウェーブ＋クリア後）で 1〜1.5時間を目標にする（推定）。
- 3〜5時間には、マップを3〜4つに増やして届かせる。まずは1マップ目を完成させ、試遊で実測する。

## 入れないもの
広告・課金・スタミナ・現実の時間を待つ要素・放置でたまる報酬・外部通信。
